# Результаты инженерного аудита

Проверка от 15 ноября 2026 года проведена для исследовательского прототипа. Проект не является промышленным средством защиты информации.

- Автоматизированные тесты: **98 пройдено**, включая 97 исходных тестов и один регрессионный тест совместимости API.
- Docker Compose: **10 сквозных сценариев** ACCEPT, QUARANTINE и REJECT; проверены MinIO, PostgreSQL, Web UI, Prometheus и Grafana.
- Kubernetes: **25 ресурсов прошли проверку схем** kubeconform. Проверка развёртывания в кластере не проводилась: API кластера был недоступен.
- Python-зависимости: после совместимого обновления FastAPI, Starlette и python-multipart pip-audit не выявил известных уязвимостей в проверенных requirements и установленных пакетах пяти контейнеров. Результат зависит от даты проверки и разрешённых транзитивных зависимостей.
- Workflow GitHub Actions проверен actionlint; удалённый запуск не проводился.

Ограничения безопасности и инструкции запуска приведены в [README.md](README.md). Контейнерные образы и системные пакеты не проходили полного сканирования CVE.
